# 野菜 API：接入重试与 Claude 路由修复

## 用户可见结果

- 再次点击“一键接入”时，不再把同一应用的未完成事务直接挡在“先恢复原设置”。助手会在同一次点击内停止该应用的本机辅助服务、按已有三方合并规则恢复未完成写入、清理该应用的旧工具密钥和未完成记录，再继续新的接入。
- 只有明确标记为 `pending` 的同一应用事务会自动恢复。已完成的接入记录、其他应用以及用户后来修改的字段不会被自动回滚。
- 自动恢复无法完整完成时仍保持失败状态，并保留“恢复原设置”作为人工兜底；界面不会声称已经恢复。
- Claude Desktop 的网关模型名改为稳定的 Anthropic 形态本地别名，真实模型名称仍显示给用户。别名只由当前已接入模型集合解析，随后把准确的真实模型 ID、计费分组和对应密钥转发给上游；未知别名不会请求上游。
- Claude Code 的 `model`、`availableModels` 和模型选择项继续保存并发送真实模型 ID，同时为客户端不认识的新模型补充 `behavesAs` 能力声明和真实 ID 描述。该声明不替换实际模型。

## 安全与恢复边界

- 未读取真实密钥，测试没有改动用户的 Claude 配置或发送付费请求。
- 未修改 Claude 或 Claude Code 程序本体。
- 未构建安装包、未升级版本、未签名、未上传或部署。
