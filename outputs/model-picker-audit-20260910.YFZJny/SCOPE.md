# 模型选择框滚动与搜索：限定排障

当前用户反馈：滚动条拖不动，打字搜索异常；未提供此轮操作录像或原始日志。此前的重启确认框修复不能代替本轮模型选择组件的验收。

当前源码观察：`ModelPicker.tsx` 在任意失焦且 relatedTarget 不在组件内时立即关闭（包括 null）；键盘 Enter/方向键/Escape 没有输入法组合态保护；点击展开会重置搜索，而键盘展开不会；过滤后 active 归零但列表滚动位置未显式复位；只以 ID/显示名的字面子串匹配，`gpt 6` 与 `GPT-6` 不能匹配。

目标：让共享选择框的拖动、滚轮、键盘、输入法与搜索有一致行为；保留精确模型 ID 和明确选择才触发 onChange 的边界。仅搜索 ID 与受审显示名，不暴露或匹配私有上游说明。两处使用方（应用接入、模型价格）复用一个修复。

允许文件：`src/configuration/ModelPicker.tsx` 及其测试，`src/model-profiles/profile.ts` 及其搜索测试，`src/workbench/workbench-v2.css` 中模型选择器局部样式，本目录证据。保留此前所有修改。不操作用户安装应用、真实配置、账户、网关或服务器；不打包/上传。

验证：修复前失败单测和隔离浏览器；真实组件加工作台 CSS；长列表滚动条拖动、滚轮、滚动后搜索、连续输入、中文组合事件、取消/外部点击/Tab、键盘上下移动/重新展开、两处选择框互不干扰；修复后生产前端构建和相邻回归。
