# 野菜API 客户端 v2 接入与上线阻塞清单

日期：2026-09-01。客户端版本：`0.2.0` 内测候选。服务端目标分支：[`codex/desktop-api-v2`](https://github.com/yeschoy/new-api/tree/codex/desktop-api-v2)，目标提交：`2e5973a3705688a81867985a7e5a899b72be674c`。

本轮只修改桌面客户端与交接文档；**未修改或部署 NewAPI、Nginx、DNS、Redis、数据库和线上配置，也未修改任何用户工具配置**。由于目标服务端分支尚未部署，当前安装包会如实显示账户服务未上线，不能据此声称线上登录、余额、充值或价格查询已可用。

## 客户端已经接好的范围

- 固定两条第一方线路：大陆优化 `https://yeschoy.com`，全球加速 `https://api.yeschoy.com`；拒绝调用者提供任意 URL、HTTP、重定向或代理。
- 读取并严格校验 `GET /api/desktop/v2/bootstrap`；只接受 `desktop-integration-v2`、精确路径、最低客户端版本不高于 `0.2.0`、固定比较汇率 `6.75` 和第一方 `/wallet`。
- 浏览器设备授权：创建、轮询、拒绝、过期、取消与浏览器打开失败都有独立状态。设备码只保留在原生进程内存，不进入网页渲染层、普通文件或日志。
- 刷新凭据保存在 macOS Keychain / Windows Credential Manager 对应的系统安全存储项中；访问凭据只存在原生进程内存。网页渲染层只收到闭合的账户、累计用量与模型价格投影。
- 读取 `/api/user/self`、`/api/log/self/stat`、`/api/user/models`、`/api/pricing` 和 `/api/status`；余额、累计消费、Token、请求数缺失时显示不可用，不补造数值。
- 模型页显示完整模型 ID。只有字段齐全的倍率计费模型才比较官网参考价与当前账号实际价；按次、阶梯表达式或缺字段模型显示不可比较。
- 充值仅用系统浏览器打开服务端声明并经过同源校验的 `/wallet`；客户端不处理支付结果，不写充值记录。
- 退出登录先尝试服务端撤销，再清除本地内存与系统安全存储；服务端不可达时也不会继续保留本地凭据。

## 服务端部署时需要做什么

1. 由技术负责人审查并部署上述固定提交或其可追溯后继提交；不要直接从未固定的分支头部署。
2. 确认 Redis 可用。设备授权为 Redis 临时状态，当前实现是 **5 分钟 TTL**，不新增数据库表，也不迁移既有用户、令牌、日志、充值或账单记录。
3. 在大陆和全球两个域名分别验证 bootstrap、授权创建/轮询/确认、刷新、撤销、账户、用量、模型、价格与钱包路径；CORS 不是桌面原生请求的授权边界。
4. 使用普通测试账号完成一次拒绝、一次过期、一次成功、一次刷新轮换、一次撤销后重放和一次退出；确认旧 refresh token、旧 access token 与旧 device code 均失效。
5. 明确 `/api/pricing` 被关闭时的行为：客户端会保留账户和用量，将价格显示为部分不可用，不把价格权限缺失误判成退出登录。

## 生产上线前的强制阻塞项

当前服务端签发的 desktop access token 仍可被通用 `UserAuth()` 当作普通站内会话使用。**在完成下面的最小权限限制前，0.2.0 只能作为内部联调候选，不能公开上线。**

技术负责人需要在服务端增加可验证的桌面会话用途，并由专用中间件执行路由白名单：

- 身份上下文必须携带不可伪造的 `login_method=desktop` / `session_purpose=desktop`（或等价字段），不能只相信客户端 Header。
- 桌面 access token 只允许：v2 当前会话、当前账户只读、自己的累计用量、自己的模型列表、价格只读，以及后续另行批准的“当前设备专用工具密钥”动作。
- 必须拒绝：修改用户资料或密码、Passkey、充值/支付写入、其他设备会话管理、通用 token 增删改查、管理员接口及未列明路由。
- 增加负向自动化测试：拿到一个真实 desktop access token 后，请求每条禁用路由都必须得到 `403`；不能只测允许路径。
- 访问令牌、刷新令牌和设备授权都要绑定用户、设备会话和用途；撤销后重放失败，刷新轮换需具备并发幂等/重放处理。

服务端此前讨论过 10 分钟验证码窗口，但目标提交实际固定为 5 分钟。上线文案、测试与运维告警必须统一采用 5 分钟；若要改为 10 分钟，需先改契约、测试和客户端展示，不可只改 Redis TTL。

## 价格口径与数据库结论

当前模型页比较的是“同一模型、当前公开倍率、当前账号分组倍率”下的单价，不是历史账单节省金额。换算公式为：

比较汇率固定为 `1 USD = 6.75 CNY`，只用于官网美元参考价的显示换算，不参与 NewAPI 实际结算。

```text
官网参考输入价（CNY/百万） = model_ratio × 2 USD × 6.75
官网参考输出价             = 官网参考输入价 × completion_ratio
野菜实际输入/输出价         = 对应官网参考价 × 当前账号 group_ratio
```

该口径直接复用 NewAPI 持续维护的模型倍率和分组倍率，不在客户端维护第二张价表。它适合当前单价比较，但不能证明历史某段时间“本应付多少、实际付多少”。历史费用对比仍需服务端输出标准化用量、当时价格版本、最终结算、退款/冲正和可比性原因；旧日志证据不足时必须显示不可比较。

本轮 **不需要数据库迁移**。未来只有在现有日志/`other` 字段不能可靠保存稳定结算键、价格历史版本、退款关联或标准化用量时，才考虑新增账本/快照表；是否迁移必须先用真实脱敏样例证明现有结构不足。

## 上线验收最短清单

- 服务端专用桌面会话白名单与负向测试通过。
- 两个域名部署同一契约，5 分钟授权行为一致。
- macOS Keychain 与 Windows Credential Manager 真机登录、重启、轮换、退出通过。
- 账户与价格缺字段、403、401、超时、无 Redis、停用价格模块均能降级且不显示伪数据。
- 安装包仍标为内测候选；自动更新和公开发布保持关闭，直到签名、更新签名链和发布权限另行验收。
