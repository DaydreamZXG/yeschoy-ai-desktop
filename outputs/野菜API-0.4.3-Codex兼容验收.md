# 野菜API 0.4.3 Codex 兼容验收

日期：2026-09-04。范围仅限桌面客户端，没有修改 NewAPI、Nginx、DNS、数据库或服务器代码。

## 修复结论

- Codex Desktop 不再只显示 `openai-response` 模型；账户可用且价格元数据声明 `openai` 或 `openai-response` 的模型均可选择。
- 同时支持两种端点时优先直接连接 Responses；仅支持 OpenAI Chat 时，客户端自动启用仅监听 `127.0.0.1` 的本地兼容层，用户界面显示“自动兼容”，无需理解协议或手动转换格式。
- 兼容层只读取系统安全存储中的 Codex 专用工具凭据，只允许转发到 `https://yeschoy.com` 或 `https://api.yeschoy.com`，上游地址和模型均不能由调用者指定。
- 转换覆盖普通与流式回复、函数工具、自定义工具、命名空间工具、工具搜索、图片/文件工具结果、用量以及 `previous_response_id` 续接历史。
- 选中的准确模型 ID 会写入客户端自有的 `yeschoy-model-catalog.json`。Codex 配置与模型目录在同一事务中写入、回读和回滚；用户自定义的外部模型目录不会被覆盖。
- 完整 API 密钥继续只保存在操作系统安全存储中；Codex 通过已签名客户端的命令式凭据助手取用，普通配置、模型目录和前端 IPC 中均不写入密钥。
- 客户端版本统一提升为 0.4.3；自动更新和遥测仍未启用。
