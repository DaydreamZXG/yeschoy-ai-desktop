## 二、环境坑（必读，省你半天）

| 坑 | 现象 | 解法 |
|---|---|---|
| vitest worktree 挂起 | RUN 横幅后永久无进展，零 import 探针也挂 | rsync 全量副本到 /tmp 跑（见下） |
| shell `rm` 被沙箱拦 | worktree 内删文件报权限 | 用文件工具 DeleteFile/Edit 代替 |
| 管道缓冲 | `npx vitest ... \| tail` 分不清挂起与运行 | 重定向到日志文件再 Read |

**/tmp 跑法（批次 5 验证过的方案）**：

```bash
rsync -a --exclude node_modules --exclude target --exclude 'src-tauri/target' \
  --exclude release --exclude dist <worktree>/ /tmp/b6-check/
ln -s <worktree>/node_modules /tmp/b6-check/node_modules
cd /tmp/b6-check && npx vitest run --exclude 'release/**' --exclude 'work/**' \
  > /tmp/vitest.log 2>&1; echo "EXIT=$?" >> /tmp/vitest.log
```

- typecheck 可以直接在 worktree 内跑：`npm run typecheck`
- Rust 测试基线 259/259（批次 3 起，`cargo test`）
- CSS 对比度：用 plain node 复刻测试算法跑，别指望 vitest
