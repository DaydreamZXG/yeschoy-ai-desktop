# 野菜API 0.4.13 Windows 运行时热修复

0.4.12 Windows 包错误地以开发服务器模式编译。安装后的 WebView 因此访问
`http://127.0.0.1:1420`，本机没有开发服务器时就显示拒绝连接。与此同时，窗口关闭
事件依赖前端确认界面；当前端没有加载时，关闭被阻止却没有可见的退出入口。

0.4.13 做了两层修复：

- 正式构建默认启用 Tauri `custom-protocol`，将当前 `dist` 页面与静态资源嵌入 EXE；
- 正式构建若关闭该能力会在编译期直接失败，避免同类坏包再次产生；
- Windows 关闭窗口改用原生中文三选项：完全退出、最小化到后台、取消；该入口不依赖 WebView 页面成功加载；
- 完全退出仍复用已有的协作式清理流程，先停止本应用拥有的本地服务，再退出进程。
