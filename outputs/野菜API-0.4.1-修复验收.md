# 野菜API 0.4.1 修复记录

日期：2026-09-03。仅客户端修改，不涉及服务器、NewAPI、数据库或线上配置。

## 已实现

- 去掉五种应用的一键接入版本白名单。版本号仅展示，应用身份和运行组件仍需存在；配置格式、回读和真实请求验证保留。
- 分开选择模型、计费分组与网络线路。分组取账户可用分组和模型可用分组的交集；选择模型后自动更新分组。
- 价格与所选分组联动，使用 NewAPI 的账户倍率和汇率。固定、按次、分时/阶梯规则分别展示；动态基础价不冒充官网价，未知规则不禁止接入。
- 激活请求携带明确分组；客户端重新检查模型和分组，并核对服务端令牌的实际 group。不覆盖其他分组令牌，不把旧分组密钥用到新分组。
- 兼容 NewAPI 创建令牌只返回 success 的响应，通过精确名称查询和专用接口继续取钥。重复接入复用同工具、同分组的有效令牌；创建后取钥失败，只清理本次已确认的新令牌。
- 本机激活串行化，避免并发操作互相覆盖；Codex 验证只在收到真实助手回复和完成事件后成功，启动事件不算成功。
