## 使用规则

1. 每轮迭代开始前对照本矩阵，改动涉及某条款时同步更新状态列。
2. 新发现「代码与 PRD 不一致」时：要么改代码对齐 PRD，要么走决策回写 PRD + 更新本矩阵，**不允许第三次静默偏离**。

4. 批次完成验收时，把对应行状态翻转为「已实现」并注明版本号。
