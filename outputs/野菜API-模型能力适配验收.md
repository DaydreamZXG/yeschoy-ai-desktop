# 模型名称与思考能力适配（未打包）

本次只修改桌面助手代码。没有改服务器、数据库、模型分组、账户权限、用户真实配置或密钥，也没有安装、签名或发布安装包。

## 修改范围

- 已核实模型的可读名称与完整 ID 同时显示，可按两者搜索；实际请求及计费始终使用原 ID。
- Codex 不再给所有模型复制“关闭/高”菜单。按已核实模型能力生成思考档位、输入类型和上下文参考值；未知模型继续默认接入，不伪造能力。
- Claude Code/Desktop 的原生目录使用可读名称和真实 ID。转换时不再把所有 max 强制改为 xhigh，自适应思考不再等于最大强度。
- Pi、DSH、OpenClaw 分别使用自己的配置格式。DeepSeek 的关闭思考转换为实际 thinking.disabled，而不是丢掉关闭意图。
- Hermes 未写入不存在的能力菜单配置。已发送的嵌套思考参数由公共网关按已知模型格式转换；没有设置思考时不替用户强制指定。
- 重新接入按完整 ID 合并，保留已有输出上限、上下文限制、兼容参数及 OpenClaw 的每模型偏好。原有文件事务仍支持恢复。
- Pi、OpenClaw 的旧单模型地址、协议及请求头不会覆盖新接入线路；Pi 的旧附加参数也不会改掉所选模型。输出预算、采样偏好与手动指定的思考默认值保留。

## 验证口径

新增测试检查准确档位、未知模型默认、四条客户端网关路径实际发送的合成 HTTP 请求、模型/分组/预算保持及重新接入后恢复原文件。继承原有全部原生与前端回归、类型检查、生产前端编译、macOS 和 Windows 编译。

正式执行结果以 `.product-governance/execution/work-package-runs.json` 中 `RU-043/WP-RU043-MODEL-CAPABILITIES` 的报告为准；测试入口为 `tests/work_packages/ru043/test_acceptance.py`。前端组件预览为 `tests/work_packages/ru043/preview.html`，仅含示例数据。

## 仍需明确的边界

- 模型参考能力不等于某个 NewAPI 分组已经支持；真实上游模型响应仍需用户实际试用。
- OpenClaw 当前代码会把 max 合并到 xhigh，不能承诺两个独立档位；本次不伪造独立 max 选项。其他已核实档位和关闭思考保留。
- Hermes 尚无已核实的任意自定义模型能力菜单配置，不注入猜测字段，不改全局默认思考。
- Pi 已手动配置的单模型思考参数仍按其原生规则优先于全局菜单。本次不擅自删除用户明确的关闭思考等默认值，不承诺已迁移这些自定义偏好。
- 第三方应用可能缩写显示名称或提供更少菜单项。已有安装需重新接入一次以刷新目录；Codex 目录首次刷新可能需要重启。不能据合成测试声称真实桌面 UI 已全部验证。
- 品牌、价格、线路、模型分组、登录和恢复设置的规则不在本次改动范围。
