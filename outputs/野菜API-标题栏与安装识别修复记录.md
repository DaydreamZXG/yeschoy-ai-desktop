## 安装识别规则

- 原 v1 接口保留；当前界面改用严格校验的 v2。
- 只查绝对搜索目录。快捷方式解析到同一文件时合并。
- macOS `.app/Contents/Resources`、`MacOS`、`Frameworks`、`Helpers` 内的程序属于桌面应用组件，不当作另一份独立命令行安装，也不执行其版本命令。
- 只有一份独立安装时自动识别；多份时仅在绝对 PATH 的最优先位置唯一时识别默认版本，不按版本新旧或路径字母顺序猜测。
- 同优先级冲突、仅常见目录出现多份或达到数量上限时保留未确认状态，提供桌面应用入口和重新检查，不要求小白删除程序。
- 默认程序获取版本失败或超时，不自动换成其他程序；不会把发现版本解释为接通、兼容或完成配置。完整路径、用户名和原始错误文本不进入结果。
- 原生标题栏颜色请求串行执行、合并中间选择，主线程完成设置后才回应。只改变窗口背景，不调用应用或系统主题覆盖，避免“跟随系统”被锁在手动主题上。
