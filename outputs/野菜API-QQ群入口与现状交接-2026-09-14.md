## 一、QQ 交流群入口 ✅

### 1.1 关键决策：静态官方分享图，不本地生成二维码

最初实现用 `qrcode` 库本地生成「群号文本」二维码，被用户否决：**QQ 加群二维码是 QQ 服务端签发的短链，客户端生成的纯数字码扫码后并不能直接加群**。最终方案：

- 用户提供的官方群分享图（`/Users/zxg/Desktop/ecc8b09f0c918963d24e6d3b6b67fc21.jpg`，1156×2055）用 `sips` 裁剪出卡片区域（`--cropOffset 334 114 --cropToHeightWidth 1160 928`），存为 [`src/assets/brand/qq-group-card.png`](file:///Users/zxg/.codex/worktrees/c485/xiaobai-ai-desktop/src/assets/brand/qq-group-card.png)（928×1160，含群头像 + 群名 + 群号 + 完整二维码）。
- 组件直接 `import qqGroupCard from "../assets/brand/qq-group-card.png"` 渲染 `<img>`，**零运行时生成、扫码即加群**。
- `qrcode` / `@types/qrcode` 依赖已从 [package.json](file:///Users/zxg/.codex/worktrees/c485/xiaobai-ai-desktop/package.json) 移除，lockfile 已用 `pnpm install --lockfile-only` 同步。

> **接手注意**：QQ 群二维码分享图可能有过期时间。若用户反馈扫码失效，重新要一张分享图、按上述 sips 参数裁剪替换 `qq-group-card.png` 即可，组件无需改动。群号 `1065665694` 是常量 [`QQ_GROUP_ID`](file:///Users/zxg/.codex/worktrees/c485/xiaobai-ai-desktop/src/workbench/QQGroupDialog.tsx#L14)，换群时同步改常量与测试断言。

### 1.2 入口位置：首页 footer

[`AppLibraryView.tsx`](file:///Users/zxg/.codex/worktrees/c485/xiaobai-ai-desktop/src/workbench/AppLibraryView.tsx#L544-L578)：卡片列表底部 `.library-footer` 右侧新增「加入交流群」文字按钮（`Users` 图标 + `text-button` 样式），与既有「接入应用」按钮并排，footer 改两端对齐。点击打开 `QQGroupDialog`。

### 1.3 对话框：[`QQGroupDialog.tsx`](file:///Users/zxg/.codex/worktrees/c485/xiaobai-ai-desktop/src/workbench/QQGroupDialog.tsx)

- 复用项目 Radix Dialog（`@/components/ui/dialog`），沿用 overlay 淡入 + 内容弹入动画；`onInteractOutside` 默认被 DialogContent 阻止，符合既有交互口径。
- 结构：标题 → 说明 → 二维码卡片图（224px 宽，`height: auto` 等比，`--shadow-tile` 投影托底）+ 扫码提示 → 大号群号（群号 `user-select: all` 方便手动选中；群名由卡片图自带，不再重复渲染）→ 「复制群号」主按钮 + 「关闭」ghost 按钮 + 右上 X。
- 复制两级 fallback：`navigator.clipboard.writeText` 失败 → 隐藏 textarea + `document.execCommand("copy")`；再失败 `toast.error` 直接展示群号兜底。

### 1.5 样式：全 token 化

[`workbench-v2.css`](file:///Users/zxg/.codex/worktrees/c485/xiaobai-ai-desktop/src/workbench/workbench-v2.css#L2825-L2930)：`.qq-group-dialog`（360px 窄模态）等一整套，颜色全走 `--ink` / `--muted` / `--faint` / `--accent` / `--subtle`（均为已定义 token），light/dark 自适应；`.library-footer` 改 flex 两端对齐。无硬编码 hex（图片本身深色卡片属资源，不属样式）。
