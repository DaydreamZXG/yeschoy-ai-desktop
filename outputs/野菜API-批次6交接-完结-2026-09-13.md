## 一、#23 授权页设备名 + 30/90 天会话感知（客户端自治）✅

### 1.1 前置核验：服务端容忍未知字段（关键风险解除）

上篇风险 #4（`deny_unknown_fields` 可能拒绝 `device_name`）已在线上实测解除：

```bash
POST https://yeschoy.com/api/desktop/v2/device-authorizations
{"client_name":"野菜API Desktop"}                                    → 200 + 合法 envelope
{"client_name":"野菜API Desktop","device_name":"probe-host"}          → 200 + 合法 envelope
```

服务端容忍未知字段，附带方案成立。（副作用仅是一个 10 分钟过期的待授权记录，无害。）

### 1.2 设备名附带（Rust 侧）

[`account_v2.rs`](file:///Users/zxg/.codex/worktrees/c485/xiaobai-ai-desktop/src-tauri/src/account_v2.rs)：

- 新增 `sanitize_device_name()`：滤除控制字符、trim、截断 64 字符、空值返回 None
- 新增 `device_name()`：Windows 取 `COMPUTERNAME`，其余平台回落 `hostname` 命令；**失败则省略字段，不阻断授权**
- `account_begin_authorization_v2` 请求体由 `{"client_name"}` 扩为可选携带 `device_name`
- 新增 Rust 单测 `device_name_sanitizer_strips_control_chars_and_caps_length`

### 1.3 30/90 天本地记账 + 两级提示（前端）

**新建 [`src/account/sessionAge.ts`](file:///Users/zxg/.codex/worktrees/c485/xiaobai-ai-desktop/src/account/sessionAge.ts)**：

- localStorage（key `yeschoy.account.sessionAge.v1`）记 `authorizedAtEpochMs` / `lastUsedAtEpochMs`
- `sessionAgeLevel()`：距授权或距上次使用（两口径取更严重者）**>25 天 → expiring**、**>80 天 → reauth**、否则 fresh；无记录 → null
- `noteSessionActivity()` 首次记录授权时间、之后只滚动最近使用；`clearSessionAgeRecord()` 清除
- 存储读写全程 try/catch 静默降级（隐私模式/存储满不影响主流程）

**接线 [`useAccountSession.ts`](file:///Users/zxg/.codex/worktrees/c485/xiaobai-ai-desktop/src/account/useAccountSession.ts)**：signed_in 观测 → 滚动记账；signed_out / session_expired → 清除。单实例 hook，记账只有一处入口。

**UI（[`AccountView.tsx`](file:///Users/zxg/.codex/worktrees/c485/xiaobai-ai-desktop/src/workbench/AccountView.tsx)）**：身份卡下方非阻断提示（`role="status"`，`data-testid="session-age-notice"`）：

- expiring：warning 色，「会话可能即将过期；近期使用一次即可自动续期」
- reauth：danger 色 + 「重新授权」按钮（调 `beginAuthorization`，**不退出当前会话**，新授权完成前旧会话仍有效）

**文案**：`workbench/copy.ts` 新增 `sessionAgeExpiringBody` / `sessionAgeReauthBody` / `sessionAgeReauthAction` × 四语言（type 从 zh 推导，typecheck 保证齐平）。
**样式**：`workbench-v2.css` `.account-session-age-notice`（token 化：`--warning`/`--warning-soft`，reauth 变体 `--danger`）。
