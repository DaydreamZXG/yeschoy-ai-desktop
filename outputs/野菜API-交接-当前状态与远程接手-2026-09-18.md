## 1. 产品边界（不要推翻）

野菜桌面助手是 **野菜API 的安装器和遥控器**，不是聊天窗口，也不在本机做协议网关。

- 登录野菜 → 看见本机应用 → 一键写入配置 → 用户在那个应用里干活 → 能恢复。
- **WorkBuddy 安装走官网** `https://www.workbuddy.cn/`，不要镜像、不要静默装。曾经加过镜像安装（`9d447d6d`），已按产品决定 revert（`5d8e35ae`），不要合回去。
- **不要**再起 `127.0.0.1` Codex/Claude 协议网关。
- **不要**把只支持 Chat Completions 的模型写进 Codex。
- 界面简体中文；侧栏是我的应用、应用接入、用量账单、设置（Claude 的密度/松绿主色在 `d17a7455`）。诊断/扫描/价格在设置「排查与高级」。
- 测试不要碰用户真实 `~/.workbuddy/models.json`。作者本机该文件里有一条自定义 GLM-5.2，接入后必须还在。

Chat 渠道要在 Codex 里能用：只能 **中转（new-api）做 Responses→Chat**。客户端不管部署。已给技术人员的说明见下文 §6。
