# 野菜API 0.4.6 内测打包范围

本次按用户确认上传客户端源码，并制作内部安装包。不是公开发布，不创建版本标签，不发布 GitHub Release，不推送自动更新，不改服务器、NewAPI、数据库或线上配置。

## 本次内容

- 交付此前完成的日常使用界面、恢复原设置、人民币额度及「官网应收 / 野菜收取 / 预计省下」展示。
- 修正旧连接第一次打开时，仅存在操作锁目录就被误判为恢复密钥丢失的问题。
- 保留安全边界：已有加密恢复记录或未知文件时，缺失的密钥仍然不能被自动替换；符号链接和读取错误不会按空目录处理。
- 回归测试仅使用临时目录与合成内容，不读取或改写真实应用配置、账户密钥。

## 安装包与源码边界

- macOS：计划构建同时包含 Intel 与 Apple 芯片的通用 DMG，使用现有 Developer ID 签名并申请 Apple 公证。
- Windows：计划构建 x64 NSIS 内测安装程序；没有 Windows 代码签名证书，不能宣称已签名或已完成真机安装测试。
- 安装包和构建回执放在忽略目录 `release/internal/0.4.6/`，不提交到源码仓库；编译工具使用独立临时目录。此前的 `release-assets/` 在暂存源码时明确排除，文件保留不删除。
- 源码只上传到原仓库 `product/yeschoy-v1` 分支，不携带标签。已知 GitHub 构建额度阻塞不通过修改计费设置解决。

## 验证与结果口径

RU-038 验证旧连接兼容性、全部当前原生单元测试、当前客户端渲染测试、类型检查与生产前端构建。实际安装包的架构、签名、公证及 SHA-256 结果另附构建回执，以实际命令结果为准。

只有安装包构建及相应校验完成后才交付下载路径。交叉编译成功不等同于 Windows 真机通过；模拟账户展示不等同于线上账单和每种工具都已实测。此前遗留的 CC Switch 旧入口集成测试也不能据此宣称全仓通过。
