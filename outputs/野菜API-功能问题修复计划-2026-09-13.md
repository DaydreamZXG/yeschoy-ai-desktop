| 原依赖项 | 原计划 | 消解方案 | 结论 |
|---|---|---|---|
| 「已撤销」状态需服务端区分 401 错误码 | 登记 NewAPI 清单 | 文案覆盖两种场景（撤销/过期都给正确引导），不区分状态 | ✅ 客户端落地（批次 1 #6） |
| 授权页显示设备名称 | 登记 NewAPI 清单（请求体加字段） | begin 请求顺带附 `device_name`，服务端忽略无害；未来支持即自动生效 | ✅ 客户端先行（批次 6 #23） |
| 30/90 天会话时效感知 | 登记 NewAPI 清单 | 本地记录授权/最近使用时间，>25 天 / >80 天两级提示 | ✅ 客户端落地（批次 6 #23） |
| 模型目录版本化服务端下发 | 登记 NewAPI 清单 | catalog.json 托管官网静态文件 + sha256 校验，客户端拉取、内置兜底；更新只换静态文件 | ✅ 客户端+静态文件（批次 2 M5） |
| 账单按 Key/线路聚合 | 依赖服务端日志新字段 | V1 只做工具×模型聚合；Key/线路维度砍掉，字段自然出现后再加 | ✅ 范围缩减（批次 3 #1） |
| 诊断 Key 有效性检查 | 无依赖 | 用现有 `/api/user/models` 401 探测 | ✅ 本就无依赖（批次 3 #2） |
| 遥测接收接口 | 需服务端 | 维持搁置（现状上传为零）；启用遥测时再单独立项，且必须先完成首启告知（批次 1 #7 前置） | ⏸ 搁置 |
| 幂等发 Key | PRD 曾列新接口 | 实现已复用分组+模型作用域 Key（acquire_token 幂等），无额外需求 | ✅ 已解决 |
