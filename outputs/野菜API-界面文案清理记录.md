# 野菜API · 界面文案清理

日期：2026-08-31。依据：用户要求应用面向普通用户，不展示工程语言；DEC-056 / REQ-039。范围：RU-014，继承既有工作台和桌面功能边界。

## 产品形态

现有工程仍是 Tauri 桌面应用。`package.json` 的开发与构建入口分别为 `tauri dev`、`tauri build`；`src-tauri/tauri.conf.json` 将 `dist` 界面打包到名为“野菜API”的独立窗口，窗口默认 1120 × 760。本次没有改成网站产品。

浏览器预览复用同一份界面，不是新安装包；它没有原生桥，因此不能证明本机应用识别、实际网络命令或原生端到端功能通过。本次未启动原生新版本，未重建、签名、公证或发布安装包。

## 界面调整

- 主界面只保留用户可理解的操作、状态、原因和下一步提示；“小白用户”“安全执行层”“目录契约”“精确版本白名单”等开发表达不再显示。
- 设置页移除发布检查清单、后端接法和未来安全实现说明。保留外观、语言、版本、隐私、自动更新关闭状态和账户功能未开放说明。
- 接入页缩短介绍；详细连接信息和操作记录收在可展开区域，不再铺陈开发验收表。按钮明确写“一键接入暂未开放”，且继续禁用。
- 概览“选择应用”按钮进入现有应用选择页，而不是不可登录的账户页；未增加新接口或配置写入。
- 模型页面使用“获取模型列表”“刷新列表”等动作名称；错误给出重试方向，不泄漏底层错误。完整模型 ID、分组、价格不可用和固定汇率仍保留；不能确认的兼容状态仍明确表示未确认。
- 诊断使用“基础连接正常”“无法连接线路”等表达，同时明确网络连接正常不保证模型可用，也不代表测速或余额检查。
- 同步简体中文、繁体中文、英文和日文；接入预览的线路名称使用当前语言。

旧版未引用的翻译资源仍保留，不删除历史代码或证据。此轮检查对象是当前应用实际渲染的页面，包括可展开内容；不会用字词过滤器隐藏用户真实模型 ID 或服务返回的文本。
