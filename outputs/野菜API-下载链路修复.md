## 已补齐的行为

1. Claude Mac 不再依赖会跳转到地区不可用页或要求浏览器确认的 DMG 入口；仅接受官方清单中唯一的当前版本 ZIP，不接受重定向切换成另一版本。
2. ZIP 在写文件前检查目录结构、名称及 Unicode 别名、类型、链接环/越界、CRC、展开与路径大小限制；先普通文件，后合法框架链接。解析器构造前也限制中央目录，防止先大量分配再检查。
3. 客户端仅在用户开始安装时读取固定 `/apps/catalog.json`，不带账户凭据；按本机应用、架构和固定厂商身份选择官方原包。镜像不可用时回到官网，实际来源反映到界面。
4. 镜像文件绑定 SHA256 和长度。断点缓存同时绑定入口、最终文件地址及期望摘要，不能因两个文件使用相同 ETag 而混用已下载字节。
5. 独立发布器要求操作员持有的分发依据和原生验证收据，按来源与原包摘要绑定。先写不可变文件，再原子替换清单，保留其他来源及上一版；失败、降级或未验证的新包不替换已发布好包。
6. 清单是公开状态的依据；清单已提交而 health 更新失败时，相同批准和收据可重放修复，即使私有同步随后失败也能恢复状态。同步定时任务仍不能写公开目录。
