## 二、各任务要点

### #12 每百万价格直显（BillingGroupPicker.tsx）

- 第一层级改为 `per-million-prices` 表格：输入/输出两行 × 官网/野菜两列，数据源 `officialInputCnyPerMillion` / `actualInputCnyPerMillion` / `officialOutputCnyPerMillion` / `actualOutputCnyPerMillion`（session.ts 既有字段，`pricingAvailable` 缺失时回退 `priceUnavailable` 文案）。
- 原「1 亿 Token 费用参考」保留为 `billing-estimate` 折叠 `<details>`（缓存价只在该示例中呈现，PRD §6.5 分层达成）。
- 样式 token 化（workbench-v2.css）；BillingPrices.test 新增 3 用例（全量价格/无价格/部分缺值）。

### #13 「查看全部模型」开关（ModelsView + ModelPicker）

- ModelsView 拆分 `allModels`/`accountModels`：默认兼容过滤；`showAllModelsToggle` 开关打开后全量显示，`disabledReason` 回调按 `modelSupportsTool` 返回「不支持此应用的协议」。
- ModelPicker `choose` 修漏洞：原实现只查外层 `disabled`，键盘 Enter 仍可选禁用项——现选择前同时校验 `disabledReason`（点击+键盘双路径）。
- 空态双分支：`allModels.length===0` → partialData（数据未返回）；`accountModels.length===0` → `noCompatibleModels` 文案 + 一键开开关按钮。
- 四语言 copy：`showAllModels` / `showCompatibleOnly` / `incompatibleReason` / `noCompatibleModels`；Workbench.test 两个集成用例（默认过滤+开关置灰；空态区分）。

### #14 汇率收敛（随 #15 落地）

- 三处 6.75 硬编码定位：① `account/readiness.ts` COMPARISON_FX（定义点）② `billing/comparison.ts` `z.literal("6.75")` schema + `675n` 换算常量 ③ `ServiceCatalogPanel.tsx` COMPARISON_FX.usdToCny（使用点）。全部属无生产引用的幽灵链路，随 #15 删除。
- 收敛后生产代码零 6.75 残留（grep 验证，仅测试 fixture 与后端交接文档断言保留）；汇率值/换算全部来自服务端 `comparisonFx`（`account_inspect_v2` → session.ts decimal 校验 → ModelsView「参考换算值」/ ConfigurationPreviewView）。
- 版本/生效日期字段服务端未下发，按客户端自治原则不补（矩阵记「已实现（部分）」）。

### #15 幽灵实现处置（删除清单）

- **`src/billing/` 整目录 7 文件**：CostComparison.tsx / CostComparison.test.tsx / comparison.ts / comparison.test.ts / comparison.css / copy.ts / test-fixtures.ts——CostComparison 无生产引用，整条依赖链（schema 校验/文案/样式/fixtures）随之孤儿化。
