# Support / 获取帮助

> [中文版本](#获取帮助)

## How to Get Help

YesChoy AI Desktop（野菜API 桌面助手）is maintained by the YesChoy team and community contributors. Please use the channels below so we can respond efficiently.

### Before Asking

1. **Read the [README](./README.md)** and [`docs/OPEN_SOURCE.md`](./docs/OPEN_SOURCE.md) — common setup and build questions are covered there.
2. **Search [existing issues](https://github.com/DaydreamZXG/yeschoy-ai-desktop/issues)** (including closed ones).

### Asking a Question

- **Usage or configuration**: [Open an Issue](https://github.com/DaydreamZXG/yeschoy-ai-desktop/issues/new)
- **General discussion**: [GitHub Discussions](https://github.com/DaydreamZXG/yeschoy-ai-desktop/discussions) (if enabled)
- **Chinese-speaking community**: YesChoy QQ group **1065665694** (in-app entry when signed in to a YesChoy station)

### Reporting Problems

- **Bug reports**: [Open an Issue](https://github.com/DaydreamZXG/yeschoy-ai-desktop/issues/new) with OS, app version, and steps to reproduce
- **Documentation issues**: same Issues tracker, with label suggestion `docs` if available
- **Security vulnerabilities**: do **not** use public issues — see [SECURITY.md](./SECURITY.md) (GitHub Security Advisories)

### Feature Requests

- [Open an Issue](https://github.com/DaydreamZXG/yeschoy-ai-desktop/issues/new) describing the use case
- Prefer discussing in an issue before opening a large feature PR

### Product / account (野菜API station)

Desktop-helper bugs belong in this GitHub repo. Account balance, billing, or station API questions for the hosted YesChoy service: [yeschoy.com](https://yeschoy.com) or the QQ group above.

# 获取帮助

> [English Version](#support--获取帮助)

## 如何获取帮助

野菜API 桌面助手由野菜团队与社区贡献者维护。请使用下列渠道，方便我们高效响应。

### 提问之前

1. **阅读 [README](./README.md)** 和 [`docs/OPEN_SOURCE.md`](./docs/OPEN_SOURCE.md) — 常见安装与构建问题已有说明。
2. **搜索 [已有 Issue](https://github.com/DaydreamZXG/yeschoy-ai-desktop/issues)**（包括已关闭的）。

### 提问

- **使用或配置**：[提交 Issue](https://github.com/DaydreamZXG/yeschoy-ai-desktop/issues/new)
- **一般讨论**：[GitHub 讨论区](https://github.com/DaydreamZXG/yeschoy-ai-desktop/discussions)（若已开启）
- **中文用户交流**：野菜 QQ 群 **1065665694**（登录野菜站点后可在应用内看到入口）

### 报告问题

- **Bug**：[提交 Issue](https://github.com/DaydreamZXG/yeschoy-ai-desktop/issues/new)，写明系统、版本与复现步骤
- **文档问题**：同样走 Issues，可建议加 `docs` 标签
- **安全漏洞**：请勿用公开 Issue — 见 [SECURITY.md](./SECURITY.md)（GitHub Security Advisories）

### 功能请求

- [提交 Issue](https://github.com/DaydreamZXG/yeschoy-ai-desktop/issues/new) 说明使用场景
- 较大改动请先开 Issue 讨论再提 PR

### 站点账户（野菜API 中转）

桌面助手本身的问题请提到本仓库。账户余额、计费或站点接口问题：请到 [yeschoy.com](https://yeschoy.com) 或上述 QQ 群。
