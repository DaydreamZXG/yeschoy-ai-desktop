# Vendor evidence, checked 2026-09-05

These sources describe reference models and native configuration contracts, not live NewAPI group capability or installed application verification.

- Shared model reference URLs are stored beside each exact ID in `src/model-profiles/catalog.json`.
- Codex optional defaults and unknown fallback: https://github.com/openai/codex/blob/main/codex-rs/models-manager/src/model_info.rs and https://github.com/openai/codex/blob/main/codex-rs/protocol/src/openai_models.rs . Empty efforts and null default mean no fabricated native choices.
- Pi model schema: https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/models.md lines 200-210, 235-237, 259-300; https://github.com/earendil-works/pi/blob/main/packages/coding-agent/src/core/model-config.ts lines 55-64, 162-175. Explicit null hides unsupported levels; map strings are wire values. `/model` reloads metadata. Main model labels may still show IDs.
- Pi effort forwarding: https://github.com/earendil-works/pi/blob/main/packages/ai/src/api/openai-completions.ts lines 728-744, 955-962. Current max is independent, no xhigh alias.
- DSH schema and defaults: https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/llm/llm-pi-ai/src/catalog.ts lines 74-85, 192-200, 548-584, 646-715; https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/llm/llm-pi-ai/src/config.ts lines 275-309. Only present `reasoningEfforts` keys are offered. Only off accepts null; null means omit effort, unlike Pi. `maxTokens` is also a request default, so no new value is emitted.
- OpenClaw schema: https://github.com/openclaw/openclaw/blob/main/src/config/types.models.ts lines 155-189; https://github.com/openclaw/openclaw/blob/main/src/auto-reply/thinking.ts lines 177-201. Current SimpleStream collapses max to xhigh before mapping: https://github.com/openclaw/openclaw/blob/main/packages/ai/src/providers/openai-completions.ts lines 264-289. Its full builder honors off mapping at lines 483-489, 528-530. Thus off is supported where documented; independent max is not advertised.
- Hermes custom-provider catalog: https://github.com/NousResearch/hermes-agent/blob/main/hermes_cli/config_providers.py lines 150-180, 480-511. YAML reasoning overrides are defaults, not supported-level catalogs: https://github.com/NousResearch/hermes-agent/blob/main/cli-config.yaml.example lines 104-121, 1193-1209. No arbitrary new UI capability fields were injected. The common gateway translates an explicitly emitted nested reasoning effort for known models; it cannot make Hermes emit a setting it never sent.

Independent source auditor and implementation reviewer identified budget-loss on wholesale catalog replacement; regeneration now merges by exact ID and preserves existing maxTokens, context caps, compat preferences and OpenClaw per-model params. Synthetic rollback fixtures verify original bytes are restored.

Connection ownership audit: Pi model-level `api`, `baseUrl` and `headers` override provider routing (https://github.com/earendil-works/pi/blob/main/packages/coding-agent/src/core/provider-composer.ts lines 130-163, 401-413). OpenClaw does the same (https://github.com/openclaw/openclaw/blob/main/src/agents/sessions/model-registry.ts lines 663-692). These three fields are cleared in managed model entries so the selected loopback provider owns the route and credentials. Other providers are untouched and original bytes remain recoverable. Pi's `samplingParams` merges last over native request fields (openai-completions.ts lines 989-992), so model/stream transport overrides are removed while token budgets, sampling and reasoning defaults remain. This deliberately preserves an explicit per-model thinking-off default even if it overrides Pi's global UI selection; no unsupported preference migration is claimed. DSH has no such per-model transport overrides (config.ts lines 290-325 and catalog.ts lines 853-894); no invented transport fields are written there.
