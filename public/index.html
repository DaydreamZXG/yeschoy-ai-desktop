三步开始用

1

下载安装

按你的系统下载安装包。官方包会自动更新；也可从 GitHub Releases 获取。

2

选应用和模型

打开助手，选择 Claude Code、Codex、OpenCode 等已安装应用，再选要用的模型。

3

确认后接入

预览页只读。点「接入」才写入；随时可「恢复原设置」，只撤回助手改过的项。
