# 完全退出时恢复设置

## 已确认目标（2026-09-14）

用户批准：完全退出默认恢复接入前设置，另保留不恢复退出；后台运行保留接入；更新与安装器替换不恢复。允许将当前已修改代码衔接为新验收基线，保留历史证据。实施单元为 RU-078。

## 实现边界

- Native 退出协调器先关闭新操作入口，等待已接纳的接入/账号事务安全结束，再逐个恢复。
- 恢复前仅请求明确识别的 Codex/Claude Desktop 安装正常关闭。多个安装、观察失败或拒绝退出时不修改该工具；不使用强杀回退。
- 使用原加密恢复记录和逐字段比较撤回；后来修改的字段保留。不删除聊天、不撤销远端 Key、不自动重新打开第三方应用。
- 无原始记录的 legacy 接入不宣称恢复成功；保留记录并列入失败工具，用户可选择保留设置退出或原有手动恢复入口。
- 命令行工具恢复磁盘配置，下次启动生效；不终止终端进程。
- 每个工具独立完成，部分失败保留恢复记录。重试不撤回成功项；“保留剩余设置并退出”仍等待正在进行的事务，不能中断写盘。
- 更新流程直接调用已有 runtime drain，安装器调用 preserve 退出；不调用用户恢复分支。
- Windows 原生关闭可在 WebView 不可用时选择恢复、保留退出、后台；失败后再次关闭可重试或保留退出。

## 验证边界

计划使用纯 Rust/临时配置 fixture、模拟 Native IPC 的 React 测试、类型检查及 Windows 交叉编译。未操作开发者真实 Codex/Claude、配置或钥匙串。编译和单元测试不能代替 Windows/macOS 真机退出验收；本变更不自动授权打包、推送或发布。
