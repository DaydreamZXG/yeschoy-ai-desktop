# New API 一键连 · 站长操作（一页）

> 目标：保留你自己的私改，只加「网页一点 → 唤起野菜桌面 → 能看余额」。

## 三步

```bash
# 0. 建议先 git commit / tag
cd /path/to/your/new-api

# 1. 先看将改什么（不写入）
/path/to/A/install-newapi-desktop-connect.sh --src "$PWD" --dry-run

# 2. 打补丁
/path/to/A/install-newapi-desktop-connect.sh --src "$PWD" --yes

# 3. 按你平时方式重建（脚本不会自动 docker up）
docker compose build && docker compose up -d
# 或：go build && 重启进程
```

## 验收（勾完再对外开）

1. HTTPS 打开 `https://你的域名/desktop/connect`
2. **先在本站登录**（控制台登入即可）
3. 点「打开桌面助手」→ 唤起野菜客户端
4. 客户端显示已连接，并能看到余额 / 用户信息
5. 同一连接码不能兑第二次

## 反代别吞路径

放行（不要整站只回 SPA）：

- `/desktop/connect`
- `/api/desktop/v2/*`
- `/api/user/auth/refresh`（新版 New API 发码前要用）

## 回滚

```bash
/path/to/A/install-newapi-desktop-connect.sh --src /path/to/your/new-api --undo --yes
# 再重新 build && up
```

## 不适合

| 情况 | 怎么办 |
|---|---|
| 仓里已有完整桌面栈（如野菜自有站） | 脚本会拒绝，不用打 |
| 只有封闭镜像、不能编译 | 看 Sidecar 方案，不跑本脚本 |
| **Sub2API** | **禁止**用本脚本，见 `Sub2API-傻瓜接入.md` |

## 出问题先看

- 点按钮提示先登录 → 浏览器没登录，或 refresh 被反代挡了
- 唤起了但没余额 → Bearer 中间件 / UserAuth 跳过没挂上，先 `--undo` 再打一次
- 编译失败 → `--undo`，把报错贴给技术人员或把本目录 `AI-提示词.md` 丢给 AI
